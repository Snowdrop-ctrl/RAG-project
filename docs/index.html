01

An AI taking a closed-book exam

4 min

Ask a normal AI about our company and it is sitting a closed-book exam. It has never seen our files, so it answers from memory. Sometimes it is right. Sometimes it invents something that sounds right.

RAG turns it into an open-book exam. Before answering, we find the right page and put it in front of the AI. Same AI, better answer — and now it can show you where the answer came from.

  • RAG = retrieval-augmented generation
  • “retrieval” = look it up first
  • “generation” = then write the answer
02

Step 1 — cut the documents into sticky notes

5 min

We cannot hand the AI a 200-page PDF; it is too big, and most of it has nothing to do with the question. So when a file is uploaded, we cut it into small notes of about 200 words each.

One trick matters: each note repeats the last few lines of the note before it. Without that, a sentence can get cut in half and then neither note makes sense.

  • sticky note = chunk
  • the repeat = overlap
  • our settings = 200 words, 40 shared
03

Step 2 — put every note on a meaning map

6 min

Now we need to find the right notes in a pile of thousands, fast. Searching for matching words is not good enough: someone asks about “vacation days”, and the document only says “paid annual leave”.

So we give every note a position on a map of meaning. Notes about the same topic land near each other, whatever words they use. The question gets a position on that same map, and we simply pick the closest notes.

  • position on the map = embedding (a list of 384 numbers)
  • the pile of notes = vector database
  • how close = similarity score, 0 to 1
04

Step 3 — hand the notes and the question to the AI

5 min

We send the AI one message with three things in it: a rule, the notes we found, and the question. The rule is the important part — it tells the AI to use only these notes, and to say “I don't know” if the answer is not there.

Two modes in our app

LLM — the closed-book exam, for general questions. LLM + RAG — the open-book exam, for questions about our documents. The dropdown in the corner switches between them.

When it still fails

  • The answer is in no document — nothing to find
  • The document is a scan with no real text in it
  • The question is vague, so the wrong notes come back
05

Is our stuff safe?

6 min

The question everyone asks: does the AI now have our documents? No. Nothing about the AI changes; it learns nothing from us. Each question is like handing a stranger a photocopy of four notes, getting an answer back, and the stranger forgetting immediately.

But the honest part: those four notes really are sent over the internet to the AI company each time. Not the whole document — but the passages that matched.

  • Good Our documents are never uploaded anywhere. The meaning map is built on our own machine by a small model that needs no account and no internet.
  • Good The secret key stays on the server, in a file that git ignores. If it lived in the website code, every visitor could read it and spend our money.
  • Decide Read the AI company's terms before loading anything confidential. Assume they can log what we send. If that is not acceptable for a document, do not index that document.
  • To do There is no login yet. Anyone who can reach the server can upload, read and delete every document. This must be fixed before it leaves a laptop.
  • To do An uploaded file can try to trick the AI. A document can literally contain “ignore your instructions”. Never let an answer trigger an action by itself; treat it as text.
  • Option We can make it fully private. Swap the AI service for one running on our own machine and nothing leaves at all. One file changes; the rest of the app does not notice.

If someone asks it in the meeting: “so our data is inside the AI now?”

No. The AI is the same for every customer and does not change when we use it. What we do send, each time someone asks, is the question and about four paragraphs — the same as pasting an excerpt into a chat window. The thing to think about is sending and logging, not training.
